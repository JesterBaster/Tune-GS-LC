# Excel character import

The system version is **0.0.1**. It must stay there until the user changes it or explicitly requests another version; see AGENTS.md.

Open **Import Excel** beside Edit character. Paste a readable Google Sheets/Excel link or select an exported `.xlsx` file, then choose **Read / Import**. Review the character, stats, skill differences, inventory and warnings. Choose the button again to commit. A nonempty character requires an explicit replacement checkbox. Its previous document and inventory are retained at `flags.angelssword.lastImportBackup` and its existing history is preserved.

Supported input is the supplied Lyrian workbook layout: Core, Abilities, Breakthrough, Inventory, locker sheets, Images, Backstory and Journals. Other arbitrary spreadsheet layouts are rejected rather than guessed. Google sharing URLs are converted to XLSX export URLs; OneDrive/SharePoint links request a download. A link must return the workbook and permit browser access. Login-only links and hosts that block cross-origin downloads require the `.xlsx` file fallback. The reader never executes workbook formulas or macros; it reads cached values, formulas as reference text, ordinary Excel notes and image relationships. Files are limited to 35 MB compressed and 100 MB expanded.

The importer reconstructs primary/secondary bases from the selected stat arrays. Race, subrace, class levels and breakthroughs are linked to the rules catalog, with source-owned bonuses, abilities and proficiencies. It uses source notes to resolve choices when consistent with the displayed totals. A uniquely plausible stat choice can be inferred from those totals and is identified in the review. Remaining stat/skill differences become separate imported adjustments. Skill allocations use the same pools as normal advancement, and remaining points stay in their pools. Crafting skill totals are preserved separately. Unknown catalog names require a mapping or an explicit choice to retain a custom record; a custom class cannot level up through an unmatched catalog entry.

Recorded EXP is a snapshot, not a new event award. Available EXP and recorded spending are preserved. Creation-funded zero-spend breakthroughs remain owned. Slow Starter's already-consumed allowance is inferred from that snapshot and shown for review, so a completed allowance is not awarded again. Exact acquisition dates and historical IP gains cannot be reconstructed reliably from totals; the review explains the resulting assumptions. All original cell notes are retained with their addresses. Conditional free-text expertise annotations that are not represented by the rules grants are not interpreted as executable conditions.

Backstory text and notes are stored in Backstory. Journal rows are grouped under Imported journals. If the importing user can create Foundry journals, they become JournalEntry documents with text pages and the character's ownership; otherwise their text stays on the character and opens in a journal window. Imported journal documents are removed if the character write fails. Existing world journals are not deleted when replacing the character's references.

The first supported embedded drawing on Images, or a literal IMAGE URL when there is no supported drawing, supplies the portrait. Embedded PNG/JPEG/GIF/WebP images are uploaded using Foundry's FilePicker API. This requires the user's Foundry file-upload permission. Portrait import can be unchecked in the review; otherwise a failed upload prevents the character commit.

Inventory rows become actual embedded Foundry Items. Quantities, prices, descriptions, source notes, carried/locker locations and zero-quantity entries are retained. The workbook's stack burden is divided by quantity to obtain burden per item; a column explicitly marked per-item/each is read directly. Core loadout weapons and armor are added if absent from Inventory and marked equipped. Their recorded guard, block and penalties are retained. Equipped item defenses affect the actor immediately and disappear when unequipped or removed. Imported weapon damage retains its dice and adjusts its Power contribution when the character's Power changes.

**Add item** selects from the library. **Custom item** supports Equipment, Weapon, Armor, Shield, Consumable, Material, Container, Spell and Other. The native item sheet keeps description and custom attributes, with quantity, burden, price, storage, equipped state, handedness, range, damage and defense settings. Inventory weapons appear in the Home action selector. Item Use posts its description and AP control to chat; quantity consumption and special effects remain manual. MP/RP ability automation is unchanged.

Validation used the actual supplied XLSX and an independent XML parser: 19 sheets, all 93 notes and an embedded portrait with matching image checksum. All primary, secondary and 21 core skill totals match; the sample produces 13 inventory entries, 8 carried burden, 3,740 Clim item value, 2,000 spent EXP and 0 available EXP. Mage source removal still removes its imported Magic grant. Additional tests cover journals, safe text, replacement confirmation, old-document backup, foreign flags/history preservation, resource reset, equipped defenses, failed-write rollback and portrait permissions. Existing resource, advancement, combat, template and catalog checks also run.

Live browser/Foundry verification remains unavailable because its administrative browser-policy check could not be verified. Link-host CORS behavior, actual uploads and live layout should be checked in Foundry after reload; no browser-policy bypass was used.
