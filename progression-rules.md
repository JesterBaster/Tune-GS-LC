# Progression rules and decisions

Source: supplied Lyrian Chronicles rulebook; current imported 0.13.1 catalog provides individual entries. The workbook is older and does not override current entry text.

- Initialize appears only on a perfectly empty actor. Primary array 5/4/4/3; secondary array 5/4/3/2/1. Race, subrace/house and grant choices are resolved before committing. Ten starting skill points are separate from racial skill grants.
- Creation starts with 1,000 class EXP, 300 creation-only breakthrough EXP, and 3 Interlude Points. Creation breakthrough spending does not raise Spirit Core; unused creation breakthrough EXP expires. Class EXP must be spent before finishing creation.
- Human adds 100 class EXP. Human–Chimera Hybrid removes that addition and Human Adaptability. Slow Starter removes 200 starting class EXP and doubles the next 500 base EXP earned. Creation grants are not earnings. Rich Parents grants 3,000 Clim.
- A class unlock costs tier × 100 EXP and one Interlude Point. Levels 2–8 cost 100 EXP, in order. There is no class-count limit. Requirements and story/teacher conditions still apply. Mentor exceptions require GM adjudication.
- The original purchase retains its cost. Later identical ability copies cost zero; class unlocks still consume an Interlude Point. Shared levels receive a blue indication; actual payments remain visible. Partial overlap, impossible abilities and mentor arrangements require GM adjudication rather than name-based guesses.
- De-level refunds the amount actually paid, never a nominal 100 EXP for a free level. Refunds decrease Spirit Core. Source grants disappear with their purchase. Removing the paid copy cannot leave its later duplicates with an undeserved refund: deletion is blocked until dependent duplicate levels are removed.
- EXP earned from dated events/sessions minus actual purchases determines available EXP. Spirit Core is actual ordinary EXP spent, not creation breakthrough spending. Existing characters retain their prior available/spent balances as opening balances.
- Primary/secondary/skill grants are locked source rows. User bonuses stay editable. Skill bases continue to derive from their secondary stat. Conditional combat buffs and expertise are retained with their conditions, not applied as unconditional stat increases.
- Breakthrough costs, repeat limits and creation-only restrictions come from their entries. Stat Training increases as specified; requirement text must be reviewed before committing story-dependent purchases.
- Chat abilities spend AP only when the initiating user presses Attack. MP/RP remain manual. Light Attack costs 1 AP (2d4 + Power), Heavy Attack 2 AP (4d6 + 2×Power; two-handed melee 5d6 + 2×Power). Initiative remains 1d4.
- History is chronological; only a GM may correct its annotations. Accounting records remain the source of balances, so changing history prose never creates EXP.
